## 🖨️ How to Save as a PDF (Print-Ready A4 Edition)

The monograph is engineered to match international **A4 Oxford Academic Print standards** (`210mm × 297mm`) with dynamic page numbering, running headers, and clean page breaks.

### Quick Step-by-Step Print Instructions:
1. Open `FINAL_EBOOK.html` in Chrome or Edge.
2. Click the floating **"🖨️ Print to PDF"** button at the bottom-right corner of the page, or press **`Ctrl + P`** (`Cmd + P` on macOS).
3. In the browser print dialog, configure the following settings:
   - **Destination:** `Save as PDF`
   - **Pages:** `All`
   - **Layout:** `Portrait`
   - **Paper Size:** `A4`
   - **Margins:** `None` or `Default` (internal CSS controls all Oxford margins)
   - **Options:** ✅ **Check "Background graphics"** *(Crucial for colored chapter badges, code blocks, unit dividers, and gradients!)*
   - **Headers and footers:** ❌ **Uncheck** *(The book has built-in academic running footers and automatic CSS page numbering)*
4. Click **Save** to generate your publication-ready PDF monograph.

### Unit 1: The World of Web Development
- **Chapter 1: What Is a Website?** — Client-server architecture, fast-food analogies, and browser rendering engines (DOM, CSSOM, Render Tree, Paint). Features inline SVG house anatomy.
- **Chapter 2: HTML, CSS & JavaScript — The Three Musketeers** — Separation of concerns, structural bones, styling skins, and behavioral muscles. Features inline SVG superhero trio.
- **Chapter 3: What is a Framework?** — Why raw DOM manipulation breaks down at scale, and how component-driven architecture simplifies applications. Features inline SVG LEGO brick stack.

### Unit 2: React 19 — The Modern Way
- **Chapter 4: Your First React Component** — Function components, return values, and JSX rendering mechanics. Features SVG component anatomy diagram.
- **Chapter 5: JSX — Writing HTML in JavaScript** — Expressions, curly braces, and compiler transformation from JSX to `React.createElement` / JSX transform runtime. Features inline SVG magic wand.
- **Chapter 6: Props — Passing Notes Between Components** — Read-only data flow, TypeScript interfaces, destructuring, and unidirectional data streams.
- **Chapter 7: State — Your App's Memory** — `useState`, state immutability, updater functions, and Fiber reconciliation triggers. Features SVG brain memory diagram.
- **Chapter 8: React Hooks Deep Dive** — Rules of Hooks, `useEffect`, dependency arrays, cleanup functions, and `useRef`. Features SVG fishing hooks diagram.
- **Chapter 9: React 19 New Powers: Actions & Optimism** — First-class Actions, `useActionState`, `useFormStatus`, `useOptimistic`, and the `use()` promise unwrap API.

### Unit 3: Angular — The Enterprise Giant
- **Chapter 10: Angular Architecture — The Enterprise Blueprint** — NgModules vs. Modern Standalone Components, TypeScript class decorators, and compilation phases. Features SVG blueprint diagram.
- **Chapter 11: Angular Templates vs JSX** — Declarative template syntax, structural directives (`*ngIf`, `*ngFor` vs modern `@if`, `@for`), and event/property bindings.
- **Chapter 12: Angular Services & Dependency Injection** — The `@Injectable` decorator, hierarchical injector trees, singletons, and decoupling business logic. Features SVG plumbing pipes diagram.

### Unit 4: Side by Side — The Rosetta Stone
- **Chapter 13: Change Detection — Zone.js vs React Fiber** — Monkey-patching async APIs vs cooperative concurrent reconciliation schedules.
- **Chapter 14: Reactivity Models — Angular Signals vs React Hooks** — Fine-grained push/pull signal graphs (`signal()`, `computed()`) vs component-level snapshot re-execution.
- **Chapter 15: State Management — RxJS Streams vs Redux / Zustand / React Context** — Observables and push pipelines vs immutable dispatch stores.
- **Chapter 16: Form Architectures — Reactive Forms vs Controlled Components & React 19 Actions** — FormGroups and synchronous validation pipelines vs controlled state and action formData.
- **Chapter 17: Routing Paradigms — Angular Router vs React Router & TanStack Router** — Declarative configuration trees and route guards vs component-centric routing.
- **Chapter 18: Performance Tuning — OnPush & Defer vs useMemo & React Compiler** — `@defer (on viewport)` block optimizations vs auto-memoizing compiler transforms.
- **Chapter 19: Testing Philosophies — Jest & RTL vs Karma, Jasmine & Angular TestBed** — User-event DOM testing vs dependency-mocked component harness fixtures.
- **Chapter 20: The Architectural Decision Matrix** — Multi-factor enterprise selection criteria (team size, longevity, strictness, ecosystem). Includes a large decision-tree SVG flowchart.

### Unit 5: Capstone Projects
