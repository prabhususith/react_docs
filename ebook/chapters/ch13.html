THE COMIC-BOOK BATTLE BEGINS!

Imagine two superhero monitors watching over a city (your web app). Their job: whenever something changes in the city — a building renovated, a road repaired — they must update the giant city map hanging in City Hall so visitors always see the current state.

🅰️ ZONE-MAN (Angular's hero) patrols every single street in the city. The moment ANY event happens anywhere — a mouse click, a timer ticking, an HTTP response arriving — Zone-Man blows his whistle and shouts: "EVERYONE CHECK YOUR SECTION!" Every citizen (component) looks around and reports whether their block changed. It's thorough. It's safe. But on a giant city, all that checking takes time. 🏙️

⚛️ FIBER-GIRL (React's hero) is smarter. She has a magical crystal ball called the Virtual DOM. When a building changes, the crystal ball shows the new city layout. Fiber-Girl compares the old map to the new crystal-ball image, marks only the CHANGED buildings with sticky notes, and sends repair crews only there. No unnecessary checking! And if her repair list gets long, she can pause, let emergency services through, then continue — thanks to her secret weapon: the Fiber Scheduler. 🔮

🅰️ Angular (Zone.js) ⚛️ React (Fiber)
Angular — Default CD
// Angular wraps browser APIs via Zone.js
// No code needed — automatic!

// Every click/HTTP/timer triggers CD
@Component({
  selector: 'app-counter',
  template: `
    <h1>{{ count }}</h1>
    <button (click)="increment()">+</button>
  `
})
export class CounterComponent {
  count = 0;

  increment() {
    this.count++; // Zone detects, CD runs
  }
}

// OnPush — only checks when:
// 1. Input reference changes
// 2. Async pipe emits
// 3. markForCheck() called
@Component({
  changeDetection: ChangeDetectionStrategy.OnPush
})

// React knows EXACTLY what changed
// because YOU tell it via setState

import { useState, useTransition } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  // React knows count changed, only
  // re-renders THIS component subtree
  return (
    <div>
      <h1>{count}</h1>
      <button onClick={() => setCount(c => c + 1)}>
        +
      </button>
    </div>
  );
}

// React 18+ batches multiple setStates

Zone.js Signals (Angular 17+) 
import { signal, computed, effect }
  from '@angular/core';

@Component({
  template: `<h1>{{ count() }}</h1>`
})
export class Counter {
  count = signal(0);

 React — memo & useMemo optimisation 
import { memo, useMemo, useCallback } from 'react';

// memo = OnPush equivalent
// Skip re-render if props unchanged
const ExpensiveChild = memo(function({ items }) {
  return <ul>{items.map(i => <li>{i}</li>)}</ul>;
});

function Parent() {
  // useMemo — cache expensive calculation
  const sortedItems = useMemo(
    () => [...items].sort(),
    [items]
  );

  // useCallback — stable function ref
  const handleClick = useCallback(
    () => doSomething(),
    []
  );

  return <ExpensiveChild items={sortedItems} />;
}

Kid Explains It! 🎮

Imagine you have 100 toy soldiers on a table. Angular is like a mom who, every time you touch ONE soldier, checks every single soldier to see if it moved. React is like a camera — it takes a photo BEFORE and AFTER you touch things, then only moves the soldiers that actually changed. React's camera (Fiber) is also polite — if Dad calls for dinner, it pauses its work and comes back later! 📸

🔬

Pro Deep Dive 🧠

Zone.js Mechanics: Zone.js patches 50+ browser APIs (setTimeout, Promise, XHR, fetch, addEventListener, etc.) at startup. After each async operation completes, it notifies Angular's ApplicationRef.tick(), which triggers dirty checking top-down through the entire component tree. This runs synchronously, blocking the main thread.

React Fiber Architecture: Fiber is a complete rewrite of React's reconciler (React 16+). The work unit is a "fiber" — a plain JS object representing a component instance. Fiber splits rendering into Render Phase (interruptible, pure) and Commit Phase (synchronous, applies DOM changes). The scheduler uses MessageChannel to yield to the browser between fiber units, enabling concurrent features like Suspense, useTransition, and useDeferredValue in React 18+.

Angular Signals vs Zone.js: Angular 17+ Signals bypass Zone.js entirely. A signal tracks its consumers at read-time (like MobX). When signal.set() is called, only components that read that signal are scheduled for re-render — O(1) precision vs Zone's O(n) full-tree walk. Angular 18+ can run zoneless with provideExperimentalZonelessChangeDetection().

Gotcha — React Stale Closures: React re-renders create new function instances. If you forget dependencies in useEffect, you capture stale state. Angular services are class instances — no closure issues. Use eslint-plugin-react-hooks to catch this.

Real-World Scenario: Live Stock Ticker 📈

A financial dashboard updates 500 stock prices per second via WebSocket.

  • Angular (default): Every WebSocket message triggers full CD — checks all 1000+ components. At 500 updates/sec that's 500,000 component checks/sec. 🔥 CPU spikes!
  • Angular (OnPush + Signals): Only the specific stock row component with the changed signal re-renders. Smooth 60fps. ✅
  • React (naive): setState in WebSocket handler causes parent re-render, cascading to all children. Same problem if not optimised.
  • React (optimised): useMemo on stock list, memo on each StockRow, useTransition to defer non-urgent price updates. Silky smooth. ✅

🅰️ Use Angular Change Detection When…

  • Your team needs automatic change detection "just works" out of the box
  • You're adopting Angular Signals for fine-grained reactivity in new code
  • Large enterprise app where OnPush discipline enforced by team convention
  • You want async pipe to auto-subscribe and trigger CD for Observables

⚛️ Use React Fiber When…

  • You need concurrent rendering — Suspense, streaming SSR
  • You want useTransition to keep UI responsive during heavy updates
  • Fine-grained control over what re-renders via memo + useMemo
  • Your team prefers explicit state mutations over magic interceptors

📋 Chapter 13 Cheatsheet — Change Detection

Zone.js — Patches browser APIs; triggers CD on any async event
ChangeDetectionStrategy.OnPush — Angular: skip subtree unless input changes
signal() — Angular 17+: fine-grained reactivity, bypasses Zone
React Fiber — Interruptible reconciler with priority scheduling
memo() — Skip re-render if props shallowly equal
useTransition() — Mark updates as low-priority; keep UI responsive
useDeferredValue() — Defer recalculation of expensive derived state
Render Phase — Interruptible; pure React work
Commit Phase — Synchronous; applies DOM mutations

Superpower Battle: NgZone.runOutsideAngular vs React flushSync

Sometimes you need to escape the framework's automatic cycle for maximum raw speed or urgent DOM updates.

🅰️ Angular: Escaping Zone.js ⚛️ React: Bypassing Batching with flushSync
runOutsideAngular.ts
import { Component, NgZone, inject, ElementRef, OnInit } from '@angular/core';

@Component({
  selector: 'app-canvas-animator',
  template: `<canvas #myCanvas width="800" height="400"></canvas>`
})
export class CanvasAnimatorComponent implements OnInit {
  private ngZone = inject(NgZone);
  private el = inject(ElementRef);

  ngOnInit() {
    // 🚫 DO NOT let requestAnimationFrame trigger full CD 60 times/sec!
    this.ngZone.runOutsideAngular(() => {
      const canvas = this.el.nativeElement.querySelector('canvas');
      const ctx = canvas.getContext('2d');

      function renderLoop() {
        // Draw 10,000 particles at 60 FPS without touching Angular CD
        ctx.clearRect(0, 0, 800, 400);
        // ... drawing logic ...
        requestAnimationFrame(renderLoop);
      }
      renderLoop();
    });
  }

  syncScoreToUI(score: number) {
    // Re-enter the zone only when we explicitly want to update the DOM!
    this.ngZone.run(() => {
      this.playerScore = score;
    });
  }
}
flushSync.tsx
import React, { useState } from 'react';
import { flushSync } from 'react-dom';

export function TerminalLog() {
  const [logs, setLogs] = useState<string[]>([]);

  const addLog = (newEntry: string) => {
    // React 18/19 batches all state updates by default
    // flushSync forces an IMMEDIATE synchronous DOM flush
    flushSync(() => {
      setLogs(prev => [...prev, newEntry]);
    });

    // The DOM is guaranteed to be updated right here!
    const terminal = document.getElementById('terminal-scroll');
    if (terminal) {
      terminal.scrollTop = terminal.scrollHeight;
    }
  };

  return (
    <div id="terminal-scroll" style={{ height: 200, overflowY: 'auto' }}>
      {logs.map((log, i) => <div key={i}>{log}</div>)}
      <button onClick={() => addLog('System ping: OK')}>Add Log</button>
    </div>
  );
}

Quiz Time! 🎯

  1. What does Zone.js do at application startup in Angular?
    AnswerIt monkey-patches browser APIs (setTimeout, Promise, fetch, etc.) to intercept async operations and notify Angular when to run change detection.
  2. What are the two phases of React Fiber rendering?
    AnswerRender Phase (interruptible, pure — builds fiber tree) and Commit Phase (synchronous — applies DOM changes).
  3. How does ChangeDetectionStrategy.OnPush improve performance?
    AnswerIt tells Angular to skip checking the component and its subtree unless: an @Input reference changes, the component requests a check manually, or an async pipe emits a new value.
  4. What is useTransition in React 18/19 used for?
    AnswerTo mark a state update as non-urgent/low-priority, allowing React to defer it and keep the UI responsive to high-priority interactions (like typing).
  5. How do Angular Signals differ from Zone.js change detection?
    AnswerSignals use pull-based, fine-grained tracking — only the components that consumed a specific signal re-render when it changes, instead of checking the entire component tree.
