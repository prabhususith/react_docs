⚛️ React 19 Hooks Quick Reference
All built-in hooks — syntax · when to use · common gotchas · React 19 new additions
🗃️ useState — Local State
const [count, setCount] = useState(0); const [user, setUser] = useState<User | null>(null); // Functional update (safe for async): setCount(prev => prev + 1);
✅ When: Simple component-local values
⚠️ Gotcha: State updates are async — never read immediately after set
⚡ useEffect — Side Effects
// Run once (mount): useEffect(() => { fetchData(); }, []); // Run on dep change: useEffect(() => { ... }, [userId]); // Cleanup: useEffect(() => { const sub = subscribe(); return () => sub.unsubscribe(); }, []);
✅ When: API calls, subscriptions, DOM mutations
⚠️ Gotcha: Missing deps = stale closure; [] ≠ "run once" in StrictMode
📌 useRef — Mutable Ref
// DOM ref: const inputRef = useRef<HTMLInputElement>(null); <input ref={inputRef} /> inputRef.current?.focus(); // Mutable value (no re-render): const timerRef = useRef<number>();
✅ When: DOM access, timers, previous value tracking
⚠️ Gotcha: Mutating .current does NOT trigger re-render
🌐 useContext — Context Consumer
const ThemeCtx = createContext('light'); // Provider: <ThemeCtx.Provider value="dark"> ... </> // Consumer: const theme = useContext(ThemeCtx);
✅ When: Theme, auth, locale — cross-tree data
⚠️ Gotcha: ALL consumers re-render on context value change
🔄 useReducer — Complex State
const reducer = (state, action) => { switch(action.type) { case 'inc': return {...state, count: state.count+1}; default: return state; } }; const [state, dispatch] = useReducer(reducer, {count:0});
✅ When: State with many sub-values or complex logic
⚠️ Gotcha: Always return new object — do not mutate state
🚀 useMemo & useCallback — Performance
// Memoize expensive value: const sorted = useMemo( () => items.sort(fn), [items] ); // Memoize callback reference: const handleClick = useCallback( () => doSomething(id), [id] );
✅ When: Expensive computations, stable refs for children
⚠️ Gotcha: Premature optimization — profile first!
⏳ useTransition & useDeferredValue React 18+
// Low-priority state update: const [isPending, startTransition] = useTransition(); startTransition(() => setFilter(val)); // Defer a derived value: const deferredQuery = useDeferredValue(query);
✅ When: Heavy list filtering, keeping UI responsive
⚠️ Gotcha: Does not replace virtualization for huge lists
✨ useOptimistic React 19
const [optItems, addOptimistic] = useOptimistic(items, (state, newItem) => [...state, newItem] ); // In form action: addOptimistic({ text: input, pending: true });
✅ When: Instant UI feedback before server confirms
⚠️ Gotcha: Must pair with server action error handling
📋 useActionState React 19
const [state, formAction, isPending] = useActionState(async (prev, formData) => { const result = await submitForm(formData); return result; }, null); <form action={formAction}> ... </>
✅ When: Form submissions with server actions
⚠️ Gotcha: State is previous action's return value
🪄 use() Hook React 19
// Read a promise (must be in Suspense): const data = use(myPromise); // Read context (can be conditional!): if (condition) { const theme = use(ThemeCtx); }
✅ When: Reading promises or context (even conditionally!)
⚠️ Gotcha: Promise must be stable — created outside render
🛠️ Custom Hook Pattern
// useFetch.ts export function useFetch<T>(url: string) { const [data, setData] = useState<T | null>(null); const [loading, setLoading] = useState(true); const [error, setError] = useState<Error|null>(null); useEffect(() => { fetch(url) .then(r => r.json()) .then(setData) .catch(setError) .finally(() => setLoading(false)); }, [url]); return { data, loading, error }; }
Hook Rule✅ / ❌
Start name with use✅ Required
Call at top level only✅ Required
Call in loops/conditionals❌ Never
Call in class components❌ Never
Call in nested functions❌ Never
Call in event handlers (mostly)❌ Avoid
Return anything you want✅ Flexible
Compose other hooks inside✅ Power move
