Project 1 · Kid-Friendly · React 19
🍿 "My Movie Review & Popcorn Rating App"

Build an interactive, animated movie review journal powered by React 19 Actions and optimistic star ratings.

🎯 What You Will Build

A fun cinema diary where kids and movie buffs can add movies, pick a mood (🍿 Classic, 🚀 Sci-Fi, 👻 Spooky), award 1 to 5 glowing popcorn buckets, and see instant optimistic updates without annoying screen flickers!

  1. Initialize the Vite + React 19 Project
    Open your terminal and run npm create vite@latest movie-reviews -- --template react. Install React 19 via npm install react@rc react-dom@rc.
  2. Design Your Movie Review Data Shape
    Define what a review looks like: an ID, movie title, popcorn rating (1-5), genre tag, and personal review notes.
  3. Create the Popcorn Rating Component
    Craft an interactive 5-star bucket selector with cute hover states and click events.
  4. Form Architecture with React 19 Actions
    Instead of messy onSubmit handlers with e.preventDefault(), use standard HTML form actions!
  5. Instant Feedback with useOptimistic
    When a user clicks "Publish Review", show the movie card instantly while simulating a half-second network delay in the background.
  6. Filter by Genre Buttons
    Add button pills (All, 🍿 Comedy, 🚀 Sci-Fi, 🦖 Adventure) to filter the list instantly.
  7. Persist to localStorage
    Save your reviews in your browser's local storage so you don't lose your reviews when you refresh the page!
  8. Delete & Favorite Functionality
    Add a red trashcan button to remove reviews and a golden heart button to pin favorites at the top.
  9. Fun Confetti Victory Animation
    Whenever someone awards 5 popcorn buckets, shoot colorful confetti across the screen!
  10. Deploy Free to the Web
    Run npm run build and drag your dist folder into Netlify Drop or Vercel to share the link with friends!

💻 Complete Working React 19 Component

import React, { useState, useOptimistic, useTransition } from 'react';

interface Review {
  id: string;
  title: string;
  rating: number;
  genre: string;
  pending?: boolean;
}

export default function MovieReviewApp() {
  const [reviews, setReviews] = useState<Review[]>([
    { id: '1', title: 'Spider-Man: Across the Spider-Verse', rating: 5, genre: '🚀 Sci-Fi' },
    { id: '2', title: 'Paddington 2', rating: 5, genre: '🍿 Comedy' }
  ]);

  // React 19 Optimistic UI hook
  const [optReviews, addOptimisticReview] = useOptimistic(
    reviews,
    (state, newReview: Review) => [newReview, ...state]
  );

  const [isPending, startTransition] = useTransition();

  // React 19 Form Action
  async function handleCreateReview(formData: FormData) {
    const title = formData.get('title') as string;
    const rating = Number(formData.get('rating'));
    const genre = formData.get('genre') as string;

    const tempReview: Review = {
      id: Date.now().toString(),
      title,
      rating,
      genre,
      pending: true
    };

    // Immediately update screen before server finishes!
    startTransition(async () => {
      addOptimisticReview(tempReview);
      // Simulate network request
      await new Promise(r => setTimeout(r, 800));
      setReviews(prev => [{ ...tempReview, pending: false }, ...prev]);
    });
  }

  return (
    <div style={{ padding: '20px', maxWidth: '600px', margin: 'auto' }}>
      <h2>🍿 My Movie Review Hub</h2>
      
      <form action={handleCreateReview} style={{ display: 'flex', flexDirection: 'column', gap: 10, marginBottom: 20 }}>
        <input name="title" placeholder="Movie Title..." required />
        <select name="genre">
          <option>🍿 Comedy</option>
          <option>🚀 Sci-Fi</option>
          <option>🦖 Adventure</option>
        </select>
        <select name="rating">
          <option value="5">⭐️⭐️⭐️⭐️⭐️ (Must Watch!)</option>
          <option value="4">⭐️⭐️⭐️⭐️ (Super Good)</option>
          <option value="3">⭐️⭐️⭐️ (Pretty Okay)</option>
        </select>
        <button type="submit" disabled={isPending}>
          {isPending ? 'Saving Review...' : 'Add Review 🎬'}
        </button>
      </form>

      <div>
        {optReviews.map(item => (
          <div key={item.id} style={{ opacity: item.pending ? 0.5 : 1, border: '1px solid #ccc', padding: 12, marginBottom: 8 }}>
            <h4>{item.title} {item.pending && '⏳'}</h4>
            <p>{item.genre} · {'🍿'.repeat(item.rating)}</p>
          </div>
        ))}
      </div>
    </div>
  );
}

Project 2 · Professional Enterprise · Rosetta Stone
🏢 "Enterprise Analytics & Telemetry Dashboard"

Comparing a multi-tenant metrics portal built side-by-side in React 19 (Hooks/Context) and Angular 18 (Signals/Injectable Services).

🏗️ Architecture Overview

A production dashboard monitoring real-time server cluster loads, memory pressure, and revenue streams with auto-polling, error resilience, and role-based access.

⚛️ React 19 Enterprise Implementation

Using custom hooks, memoized metrics cards, and TanStack caching.

// MetricsDashboard.tsx
import { useQuery } from '@tanstack/react-query';
import { useMemo } from 'react';

export function MetricsDashboard() {
  const { data, isLoading, error } = useQuery({
    queryKey: ['cluster-telemetry'],
    queryFn: fetchMetrics,
    refetchInterval: 5000, // 5s poll
  });

  const healthRatio = useMemo(() => {
    if (!data) return 100;
    return (data.healthy / data.total) * 100;
  }, [data]);

  if (isLoading) return <SkeletonLoader />;
  if (error) return <AlertError err={error} />;

  return (
    <section className="dashboard-grid">
      <MetricCard
        title="Active Nodes"
        value={data.nodes}
        status={healthRatio > 90 ? 'ok' : 'warn'}
      />
      <CpuSparkline series={data.cpuHistory} />
    </section>
  );
}
🅰️ Angular 18 Enterprise Equivalent

Using standalone components, Signals, and reactive Dependency Injection.

// metrics-dashboard.component.ts
@Component({
  selector: 'app-metrics-dashboard',
  standalone: true,
  imports: [MetricCardComponent, CpuSparklineComponent],
  template: `
    @if (metricsSvc.loading()) {
      <app-skeleton />
    } @else {
      <section class="dashboard-grid">
        <app-metric-card
          title="Active Nodes"
          [value]="metricsSvc.data()?.nodes"
          [status]="healthStatus()" />
        <app-cpu-sparkline
          [series]="metricsSvc.data()?.cpuHistory" />
      </section>
    }
  `
})
export class MetricsDashboardComponent {
  protected metricsSvc = inject(MetricsService);

  // Angular computed Signal
  protected healthStatus = computed(() => {
    const d = this.metricsSvc.data();
    if (!d) return 'ok';
    return (d.healthy / d.total) > 0.9 ? 'ok' : 'warn';
  });
}

🎯 Key Enterprise Takeaways:

React 19 empowers teams with extreme compositional flexibility, leveraging lightweight custom hooks and fine-grained concurrent transitions. In contrast, Angular 18 delivers a standardized out-of-the-box battery with built-in dependency injection, signals, and CLI scaffolds that make cross-team maintenance effortless in massive enterprise codebases.
